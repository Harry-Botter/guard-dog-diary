## About

### Security is hard to learn

Security news feels scary and confusing for beginners. Guard Dog Diary turns it into a friendly dog who patrols the world for you.

- Beginners don't know where to start with security
- Meet Pochi, a trainee guard dog with a red bandana
- Pochi acts like a white hat hacker and learns attacks to protect people
- Pochi is your teacher, so nothing feels scary

### Watch Pochi patrol the map

Pochi runs around a world map on his own. When he finds a threat, he reports it and you decide what to do.

- Press Start and Pochi runs to glowing dots on the world map
- Each report shows where the problem is, how urgent it is, and how to fix it
- Choose "Fix it" or "Watch" and earn XP
- Found threats become stickers in the Threat Book

### Learn by watching him grow

As you answer reports, Pochi levels up and earns reward stickers. You learn real security habits along the way.

- Pochi changes his look: sunglasses, cape, headset, crown
- A diary notebook records every choice you made
- Simulated attack news gives Pochi extra XP
- Next idea: pick a start point for each patrol
